# CPC Prep Hub

A free study and application organizer for Saudi high school students preparing for Aramco CPC/CDPNE, Qudrat, Tahsili, IELTS, Safeer and university applications abroad (UC, Common App, UCAS).

## Features
- Dashboard with exam countdowns, progress by pillar, upcoming deadlines and goals
- Task planner organized into four pillars: GPA, Qudrat & Tahsili, Aramco CPC, Study Abroad & Safeer
- Month and week calendar
- Goals & targets with score history
- Study topics checklist
- University shortlist with application checklist
- Essay editor with live word count
- Extracurriculars in Common App format (150-character counter)
- Resources, official links and a documents checklist
- Dark mode, backup and restore

## Use it
Open `index.html` in a browser, or turn on GitHub Pages for this repo (Settings → Pages → deploy from the main branch).

Your data is saved in your own browser (localStorage). Nothing is sent to a server. Use **Settings and backup → Download backup** to keep a copy or move it to another device.

The AI Advisor and file attachments only work when the page is opened inside Claude.

Requirements and deadlines change every year. Always check the official sites linked in the app.
